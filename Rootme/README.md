# TryHackMe - RootMe

## Overview

This repository documents my penetration testing assessment of the **RootMe** room on TryHackMe. The objective was to perform reconnaisance, enumerate services, gain initial access, escalate privileges, and document the complete methodology.

## Objectves

 - Perform reconnaissance
 - Enumerate the target
 - Gain initial access
 - Escalate privileges
 - Capture the user and root flag
 - Document all findings professionally

 ## Skills Demonstrated
  - Network Scanning (Nmap)
  - Web Enumeration
  - Directory Fuzzing
  - File Upload Exploitation
  - Reverse Shell
  - Linux Enumeration
  - SUID Privilege Escalation
  - Report Writing

## Disclaimer
This repository is for educational purposes only. All testing was performed in the authorised TryHackMe lab environment.
